# Report summary

Тема ВКР: разработка методов обнаружения и обработки редких и критических сценариев в мультимодальном восприятии систем ADAS для повышения безопасности в сложных погодных и дорожных условиях.

В MVP показана базовая логика будущей системы:

1. Получить результаты от нескольких сенсоров.
2. Учесть погодные условия, видимость и окклюзию.
3. Объединить оценки сенсоров.
4. Посчитать неопределенность и риск.
5. Выдать флаг критического сценария.

MVP не является финальной моделью 3D-детекции. Он нужен, чтобы показать минимально рабочий pipeline и подготовить основу для дальнейшей работы с nuScenes, DENSE или симулятором CARLA.
