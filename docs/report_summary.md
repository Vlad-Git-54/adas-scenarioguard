# Краткое резюме ВКР

Работа посвящена scenario-level оценке критичности дорожных сцен для ADAS. Прототип не заменяет полный perception stack и не является системой управления автомобилем; он проверяет слой, который связывает признаки наблюдения, надежность, неопределенность и риск пропуска критической ситуации.

## Данные

Основной эксперимент выполнен на реальных аннотациях KITTI Object Detection. Подготовленная таблица содержит 7481 сцену: 4488 в train split, 1496 в validation split и 1497 в test split. Синтетические сцены не используются для обучения и расчета метрик.

Метка `critical_scene` отсутствует в KITTI как готовая экспертная разметка. В работе она получена фиксированным правилом из класса объекта, расстояния, положения относительно траектории, occlusion и truncation.

## Модель

Primary model: `proposed_reliability_logreg`. Модель использует интерпретируемые табличные признаки и порог, выбранный на validation split. Test split применяется только для финальной оценки.

## Результаты

| Метрика | Значение |
|---|---:|
| Precision | 0.885 |
| Recall | 0.937 |
| F1 | 0.911 |
| Accuracy | 0.933 |
| ROC AUC | 0.981 |
| PR AUC | 0.970 |

Матрица ошибок на test split: TP = 509, FP = 66, FN = 34, TN = 888.

## Ограничения

KITTI не содержит radar и готовой ADAS-метки критичности, поэтому выводы относятся к проверяемой табличной постановке на реальных аннотациях. Перенос к raw image/LiDAR/radar pipeline требует отдельного набора данных, новой архитектуры и независимой валидации.
