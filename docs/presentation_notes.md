# Presentation notes

Ключевой тезис для защиты MVP:

> Я сделал минимальный прототип, который показывает логику моей ВКР: система принимает мультимодальные признаки сцены, оценивает надежность сенсоров в плохую погоду, считает риск и помечает редкие критические сценарии. Это пока не полноценная ADAS-модель, но это рабочий каркас для будущих экспериментов с реальными датасетами.

Что можно показать:

- запуск CLI на одной сцене;
- JSON-вход и JSON-выход;
- таблицу метрик на 10 контрольных сценариях;
- demo-скриншот из README.
