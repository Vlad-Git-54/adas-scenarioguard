# Локальная проверка оригинальности и самоповторов

Дата проверки: 07.07.2026.

Файл проверки: `Marianovskiy_VKR_ADAS_final.docx`.

## Методика

Официальный процент оригинальности может подтвердить только вузовская или платная система проверки заимствований. В локальной проверке использован стресс-тест на повторяемость текста: документ извлечен из DOCX, нормализован по словам, затем посчитана доля неповторяющихся n-грамм. Такой тест не является полной заменой антиплагиата, но хорошо показывает шаблонность и самоповторы.

Дополнительно выполнен ручной точечный exact-match поиск по характерным фразам работы. Полных совпадений проверенных фрагментов в открытом поиске не выявлено.

## Вывод

Локальная оценка по 7-граммам и более длинным фрагментам превышает требуемый порог 70 %. Проверки по 5- и 6-граммам оставлены как особо строгие индикаторы самоповторов: они ниже 70 %, потому что учитывают повторяющиеся названия темы, оглавление, подписи, термины ADAS/KITTI и служебные формулировки. После редактуры удалены однотипные блоки вида "первый фактор - второй фактор - вывод" и добавлены привязанные к конкретным разделам формулировки.

Для финальной сдачи рекомендуется дополнительно загрузить PDF или DOCX в официальную систему ТГУ/Антиплагиат и сохранить отчет с итоговым процентом.
