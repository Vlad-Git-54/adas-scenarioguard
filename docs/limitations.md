# Ограничения исследования

Проект проверяет scenario-level методику оценки критичности сцены на признаках, рассчитанных из аннотаций KITTI Object Detection. Это позволяет воспроизводимо обучить и проверить модель на реальных дорожных данных, но не заменяет испытания полноценного ADAS-модуля на потоках камеры, LiDAR и radar.

## Данные

- KITTI Object Detection содержит реальные городские сцены и 2D/3D-аннотации объектов.
- В наборе нет готовой метки `critical_scene`; она рассчитана фиксированным правилом из доступной разметки.
- В основном эксперименте не используются синтетические сцены для обучения или расчета метрик.
- KITTI не содержит radar, поэтому radar не входит в основной набор признаков.

## Модель

- Основная модель `proposed_reliability_logreg` является интерпретируемой логистической регрессией.
- Модель работает на табличных признаках сцены, а не на исходных изображениях или облаках точек.
- Высокий ROC AUC и PR AUC показывают качество выбранной постановки, но не доказывают готовность решения к установке на автомобиль.

## Перенос на промышленный контур

Для практического применения нужен следующий этап: raw sensor pipeline, проверка на погодных сценариях, отказах датчиков, дополнительных датасетах, синхронизации sensor fusion и независимой валидации. Текущий результат остается воспроизводимым CPU-friendly прототипом и не подменяет отдельное обучение моделей на сырых сенсорных данных.
